# AI 提示词合集

## 生成短篇视觉小说剧情

```text
请帮我设计一个适合 Ren'Py 新手制作的短篇视觉小说剧情。

限制：
1. 总时长 5-10 分钟。
2. 角色不超过 3 个。
3. 场景不超过 5 个。
4. 需要 2 次玩家选择。
5. 需要 3 个结局。
6. 剧情适合转成 Ren'Py 的 label、menu、jump、if 结构。

请输出：
- 世界观
- 角色设定
- 场景列表
- 分支流程图
- 每个结局触发条件
- 素材清单
```

## 转成 Ren'Py 脚本

```text
你现在是一个 Ren'Py 视觉小说开发导师。
我是一名零基础新手。
请帮我把下面的故事设定转成 Ren'Py 可用的项目结构和 script.rpy 代码。

要求：
1. 先输出故事结构。
2. 再输出角色列表。
3. 再输出场景列表。
4. 再输出图片和音频素材命名建议。
5. 最后输出可复制到 script.rpy 的代码。
6. 每段代码后面用中文解释作用。

我的故事设定：
【在这里填写故事设定】
```

## Ren'Py 报错排查

```text
我在 Ren'Py 中遇到了报错，请帮我定位问题。

我的目标：
【我想实现什么效果】

报错内容：
【完整复制 Ren'Py 报错】

相关代码：
【粘贴报错附近 20-50 行代码】

我的文件结构：
【粘贴 images/audio 文件夹结构】

请你：
1. 判断最可能的错误原因。
2. 指出具体哪一行有问题。
3. 给出修复后的代码。
4. 告诉我如何避免再次出现。
```
